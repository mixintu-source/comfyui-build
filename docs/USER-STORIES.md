# 用户故事适配评估

> 评估对象：2026-11-06 提供的用户故事清单，以及 `E:\Desktop\豆包.md` 的纯静态前端方案。
> 状态含义：✅ 已支持 / 🟡 部分支持 / ⏸ 后续设计 / ❌ 不建议采用。

## 一、配置

| 用户故事 | 状态 | 实现说明 |
|---|---|---|
| 源根目录、目标根目录重启后仍生效 | ✅ | `data/config.json` 原子写入；`config_store` 启动读取；测试覆盖重启后读取 |
| 保存时知道错在哪：不存在、不是目录、不可写、和源相同、位于源内部 | ✅ | `POST /api/config/validate` 返回结构化 `errors/warnings`；保存接口拒绝有错误的配置；可选 SD 目录缺失只告警 |
| 迁移前看到需要多少字节、目标盘剩余多少；空间不够明确拒绝 | ✅ | `POST /api/migrate/preflight` 返回 `need_bytes/free_bytes/files`；`/api/migrate` 再次校验并以 409 拒绝；前端在任务开始前显示检查失败原因 |

补充：目标根目录可填 ComfyUI 根或 `models/`；写入前会建目录，空间检查针对目标所在磁盘。

## 五、迁移执行

| 用户故事 | 状态 | 说明 |
|---|---|---|
| 立刻拿到任务号，页面不阻塞 | ✅ | `POST /api/migrate/tasks` 立即返回 `task_id`，复制在后台线程执行 |
| 实时进度：字节/百分比/速度/ETA | ✅ | `GET /api/migrate/tasks/{id}` 返回字节、百分比、速度、ETA；前端 300ms 轮询 |
| 取消任务且目标端不留半截文件 | ✅ | `POST .../cancel` 置取消信号；复制循环在块边界停止，`.part` 临时文件清理；已完成文件保留 |
| 复制完成显示源/目标哈希与一致性 | ❌ | 未实现哈希 |
| 哈希不一致时明确失败且保留源文件 | ❌ | 未实现哈希 |
| 目标已有同内容文件时跳过并视为已校验 | ✅ | 大小 + 首尾 1 MB 快速指纹；不是完整 SHA256 |
| 同名但大小/内容不同的目标文件 | ✅ | 预检列出风险；弹窗显示「覆盖」勾选项，未勾选时禁止执行；勾选后才覆盖 |

**关于异步**：已采用后台线程 + 轮询，而不是 SSE。原因是本地单用户、任务数量少，轮询实现简单、断线可恢复；SSE 会额外引入连接生命周期。**关于哈希**：当前使用「大小 + 首尾 1 MB 快速指纹」，能提示同名不同内容，但仍不是完整 SHA256；完整哈希与日志列列为后续。

任务状态保存在进程内存；服务重启后，进行中的任务会丢失，但已完成文件和迁移日志保留。

## 八、对 `豆包.md` 纯静态前端方案的意见

| 建议 | 结论 | 理由 |
|---|---|---|
| 用 `index.html + app.css + app.js` 替换 Astro | ❌ 不建议现在采用 | 当前 Astro 构建产物已经是纯静态文件，由 FastAPI 同源托管；再改原生三件套会丢掉组件化与类型检查，收益只是少一个构建步骤 |
| CORS `allow_origins=["*"]` | ❌ 不采用 | 同源部署不需要 CORS；通配符会扩大本地服务的攻击面 |
| `/api/config/validate` | ✅ 已采用 | 保存前结构化校验 |
| `/api/migrate/preflight` | ✅ 已采用 | 迁移前空间检查 |
| `/api/migrate` 返回 `task_id` + SSE 进度 | 🟡 已部分采用 | 采用 `task_id` + 300ms 轮询（字节/百分比/速度/ETA）；未用 SSE |
| 哈希校验、删除源二次确认 | 🟡 部分 | 已采用删源门控、二次确认、快速指纹与覆盖确认；完整 SHA256 与独立删源仍在后续 |
| `extra_model_paths.yaml` | ⏸ 后续 | 可作为删除完成后的附加产物 |
| 扫描预览 + 多选导入 | ✅ 已采用 | 避免“扫描即全量入库” |
| 工作流格式列/类别标签 | 🟡 部分 | 类别已有；格式未单独入库展示 |

## 九、后续建议

1. **完整哈希校验**：复制完成后流式计算源/目标 SHA256；新增 `sha_src/sha_dst` 列；哈希不一致则失败且绝不删源。
2. **独立删源**：只在哈希通过后开放 `/api/delete-source`，并要求一次性确认 token。
3. **extra_model_paths.yaml**：按已迁移目录生成参考片段，展示而非自动改 ComfyUI 配置。
4. **全局大小排序**：模型页增加“平铺按大小”视图，配合批量迁移优先搬大文件。
5. **自动发现**：扫描常见 ComfyUI 安装位置，作为工作流目录选择的建议项，而不是自动导入。
6. **索引缓存**：模型数量达到数万时，为 `ModelCatalog` 增加 mtime 失效缓存。
7. **审计**：日志增加哈希、操作类型（复制/剪贴/删除）、目标根标识。
8. **任务持久化**：把内存任务状态落入 SQLite，服务重启后可恢复或标记中断。
