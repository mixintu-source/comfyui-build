# 用模型相对路径作为模型身份

工作流 JSON 里的模型引用通常只是文件名，而磁盘上的同一个文件可能同时存在于 ComfyUI 与 SD 两个根目录，也可能带子目录。若直接拿引用当身份，共享分析、树形分组和迁移目标路径都会不稳定。

因此模型身份统一为 `models/<目录>/<文件名>`：导入时用已配置根目录的递归索引把引用解析成该形式；解析不到时记为 `models/(未找到)/<文件名>` 并标记 `found=0`。同名文件跨目录出现时，按相对路径最短、再按字典序取第一个。代价是根目录配置补齐后，旧占位仍会显示为“未找到”，直到重新导入或执行一次迁移才被纠正；这比让两套身份并存更容易解释。
