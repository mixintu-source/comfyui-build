# 路径统一以正斜杠存储与展示

Windows 用户从资源管理器粘贴的是反斜杠路径，但反斜杠在 JSON、日志、URL、HTML 属性里都需要转义，容易在前后端之间产生 `\\` 与 `/` 两套写法。

因此所有用户路径在进入系统时统一规范为 `/`（保留 `//server/share` 形式的 UNC 前缀，盘符根保留 `G:/`）。数据库里的 `file_path`、`src_path`、`dst_path` 以及 API 返回也一律是正斜杠；真正的文件 I/O 仍交给 `pathlib`，Windows 原生接受正斜杠。代价是数据库需要一次启动时的归一化迁移，收益是配置、日志、界面和接口只有一种路径写法。
