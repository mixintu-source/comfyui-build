# ComfyUI 模型迁移管理 V1.0 使用说明

## 一、运行要求

- Windows 10 / Windows 11，64 位。
- 不需要安装 Python、Node.js 或数据库。
- 首次运行时 Windows 防火墙可能询问，请选择“允许访问”（仅本机 127.0.0.1 使用）。

## 二、启动

1. 将整个压缩包解压到任意可写目录，例如 `D:\ComfyUI-Model-Migrator`。
2. 双击 `启动.cmd`（或 `Start-Portable.cmd`）。
3. 会打开一个命令行窗口，并自动打开浏览器：
   `http://127.0.0.1:8765`
4. **不要关闭命令行窗口**；关闭窗口即停止服务。
5. 如果 8765 被其他程序占用，窗口会显示新的端口，请以窗口中的地址为准。

> 不要把 `runtime`、`web`、`launcher.py` 等文件单独移走；它们必须放在同一个文件夹内。

### Windows 提示“已保护你的电脑”

本程序没有购买代码签名证书，Windows 可能弹出 SmartScreen 提示：

- 点「更多信息」→「仍要运行」。
- 如果使用安全软件，请将整个解压目录加入信任。
- 本程序只监听本机 `127.0.0.1`，不会上传任何数据。

## 三、首次配置

进入「路径配置」：

1. ComfyUI 模型根目录：例如 `G:/ComfyUI-Shared/models`，也可以填 ComfyUI 根目录。
2. SD 模型根目录（可选）。
3. 迁移目标根目录：例如 `I:/models`。
4. 工作流 JSON 目录：ComfyUI 的 `user/default/workflows` 目录。
5. SD 工作流目录（可选）。
6. 点「保存路径」。

然后：

- 点「扫描工作流目录…」，勾选需要导入的 JSON，点「导入所选」；
- 或在「拖拽上传工作流 JSON」区域拖入 JSON 文件。

## 四、使用流程

- **主页面**：查看模型/工作流数量、最近迁移。
- **模型文件**：按目录分组，默认折叠；点目录行展开；勾选文件后「批量迁移」。
- **工作流**：搜索、展开模型树、查看每个模型的迁移状态。
- **日志记录**：查看成功/失败记录；点击源/目标文件名可复制；可清空或删除日志。
- **路径配置**：修改目录、允许删除源文件开关、扫描导入。

迁移默认只复制。只有勾选「允许删除源文件」后才会显示「剪贴」入口；剪贴会在复制成功后删除源文件，请谨慎使用。

## 五、数据与备份

- 配置、日志、上传缓存保存在启动脚本同级的 `data/` 目录。
- 备份时复制整个 `data/` 目录即可。
- 删除发布包不会自动删除 `data/`，请自行清理。

## 六、常见问题

**双击没反应 / 被安全软件拦截**
- 确认解压完整，`runtime\python.exe` 和 `启动.cmd` 在同一层目录结构内。
- 将整个文件夹加入安全软件信任，再重新双击。

**浏览器没有自动打开**
- 手动打开命令行窗口中显示的地址，例如 `http://127.0.0.1:8765`。

**端口被占用**
- 关闭重复启动的窗口；程序会自动选择新的端口，以窗口输出为准。

**页面显示旧版本**
- 按 Ctrl+F5 强制刷新；或关闭窗口后重新启动。

**如何退出**
- 在命令行窗口按 Ctrl+C，或直接关闭窗口。

## 七、安全说明

- 服务只监听 `127.0.0.1`，数据不离开本机。
- 不提供账号体系；请勿把端口暴露到公网。
- 迁移是文件操作，剪贴/覆盖前请确认目标位置和备份。
